# Delivery Metrics Reference

Use trends and context, not isolated scores. DORA measures deployment frequency, lead time for changes, change failure rate and time to restore service. Flow metrics add velocity, time, efficiency, load and distribution. Complement them with escaped defects, flaky-test rate, vulnerability remediation time, SLO performance and toil.

For every metric record definition, unit, source, period, denominator, exclusions, owner and decision it informs. Never use delivery metrics as individual performance rankings.
